# 好奇心 · Curiosity

让她自己上网翻新东西，看见有意思的就攒着，回头讲给你听。

不是搜索框，是一个**会自己产生谈资**的东西：定时出去翻，攒到真正值得讲的才开口，没料就不吭声。

## 它怎么工作

```
定时器（默认每 3 小时）
   ↓ 随机挑一个感兴趣的方向
联网搜索（复用你 AstrBot 里带联网能力的 provider）
   ↓ 把原文拆成「一条一条」：标题 / 是什么 / 为什么有意思 / 链接 / 有趣度打分
本地 SQLite（URL + 标题指纹去重，同一件事不会攒两遍）
   ↓ 攒够 N 条，且不在免打扰时段
用她自己的口吻组织一段话
   ↓
主动发到你私聊
   ↓ 讲过的永久标记 delivered=1，永不再讲
```

## 为什么值得

- **她有自己的消息源**：不用你喂链接，不用你问「最近有什么新闻」
- **不重复**：指纹去重 + delivered 标记，同一件事不会讲两遍
- **会挑**：每轮让模型自己给 1-10 分，讲的时候优先讲高分的那条
- **有脾气**：攒不够就不开口，免打扰时段闭嘴，不会变成机器人播报

## 指令

| 指令 | 干什么 |
|---|---|
| `/翻翻 [方向]` | 立刻出去翻一轮，不给方向就随机挑 |
| `/攒了什么` | 看看手里有多少还没讲的 |
| `/讲讲` | 马上挑最有意思的讲给你听 |
| `/翻翻状态` | 最近几轮翻得怎么样 |
| `/清空攒的` | 把没讲的都扔了 |

## 配置要点

| 键 | 说明 |
|---|---|
| `interval_hours` | 多久翻一次，默认 3 小时，`0.25` 就是 15 分钟 |
| `search_provider_id` | 用哪个 provider 联网，默认 `openai/deepseek-chat-search` |
| `target_umo` | 讲给谁，格式 `平台ID:FriendMessage:QQ号` |
| `deliver_threshold` | 攒够几条才开口，默认 4 |
| `quiet_hours` | 免打扰时段，默认 `[1, 8]` |
| `topics` | 感兴趣的方向列表，每轮随机挑一个 |
| `persona_hint` | 讲东西时的口吻设定 |

## 数据库

`data/plugin_data/astrbot_plugin_curiosity/curiosity.db`

- `finds` —— 攒下的条目，`delivered` 标记是否讲过
- `runs` —— 每一轮的日志：方向 / 成败 / 抽出几条 / 新增几条 / 耗时
- `prefs` —— 上次翻的时间等状态

想知道它背着你攒了什么：

```sql
SELECT title, gist, score FROM finds WHERE delivered=0 ORDER BY score DESC;
```

## 依赖

无额外依赖。只要求 AstrBot 里有一个能联网的 provider，并且已经可用。
